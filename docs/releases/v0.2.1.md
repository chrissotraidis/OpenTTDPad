# OpenTTDPad 0.2.1: right on a TV

OpenTTDPad 0.2.1 fixes playing on a TV or monitor connected to an iPad.

## What's new

- **Right on a TV.** When iPadOS shows OpenTTDPad on a TV or monitor (an extended display), the game now comes up the right way up and fills the screen; the iPad no longer limits it to landscape, which left it rotated or squeezed on the external screen ([#13](https://github.com/chrissotraidis/OpenTTDPad/pull/13)).

## Install

- **Download** `OpenTTDPad-unsigned.ipa` below and install it with a sideloading tool that signs it with your Apple ID, such as Sideloadly or AltStore, or sign it yourself with Xcode or `devicectl`. Install it over 0.2.0 with the same Apple ID; your saves stay.
- **Build it with [PadMint](https://github.com/chrissotraidis/padmint)** on an Apple Silicon Mac with Xcode 26 or newer.
- **Build from source:** see [Get OpenTTDPad](https://github.com/chrissotraidis/OpenTTDPad#get-openttdpad).

Requires an iPad on iPadOS 17 or later. iPhone is not supported.

## What has been checked

- A development-signed build of this commit on an iPad Pro 12.9-inch (6th generation) connected to a 1280×720 TV, November 2026: installed in place over the existing app with saves kept, opened from PadMint and played.
- From a clean checkout: `scripts/check-local.sh` (hygiene, host tests, Simulator UI tests, device build), `build-device.sh`, `package-ipa.sh`, `package-source-release.sh` and `verify-release.sh` pass. The IPA has the same 198 entries as 0.2.0's.
- PadMint's player check (Apple's Python, an empty PadMint folder) built the app from the release checkout. Every file below passes PadMint's content audit and the private release gate.
